# Phạm vi dự án

HalaOS là hệ điều hành giáo dục mã nguồn mở cho STM32F103C8 Blue Pill thật.
Dự án minh họa boot chain, kernel, scheduling, process/thread, syscall, IPC,
VFS, shell, compiler nhỏ, VM và application store trong giới hạn 64 KiB Flash
và 20 KiB SRAM.

Dự án không tuyên bố là Linux, POSIX-compliant đầy đủ, commercial RTOS hoặc
production-qualified firmware.

Chủ sở hữu dự án: HALA Academy — https://hala.edu.vn
